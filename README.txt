Knit Guide MVP — 사용 안내

파일 구성
- index.html: 아이패드용 웹앱

간단 실행
1. 컴퓨터에서 index.html 파일을 브라우저로 열거나, 정적 호스팅에 올려 HTTPS 주소로 접속합니다.
2. PDF를 열기 전에 시작단의 작업 면(1단=겉면 RS / 안면 WS)을 선택합니다. 기본값은 안면(WS)입니다.
3. 'PDF 열기'로 도안을 선택합니다. PDF 파일이 서버로 업로드되지는 않습니다.
4. 파란 슬라이딩 가이드를 드래그해 작업 중인 단을 표시합니다.
5. 다음 단/이전 단, RS/WS, M1R/M1L 툴팁을 사용합니다.
6. 최근 PDF 및 진행 상태는 같은 브라우저의 IndexedDB/localStorage에 저장됩니다.

아이패드 사용
- 정적 호스팅(GitHub Pages, Netlify 등)에 index.html을 올리고 Safari에서 URL을 여세요.
- 공유 > 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.
- 저장한 파일과 설정은 같은 브라우저/도메인 안에서만 유지됩니다.

실물 책 사진 사용
1. 휴대폰이나 아이패드에서 '사진 찍기'를 눌러 책의 도안 페이지를 촬영합니다. 기기에서 카메라를 지원하지 않으면 파일 선택 화면이 열릴 수 있습니다.
2. 기존 사진은 '사진 추가'로 선택합니다. 여러 장을 추가하면 이전/다음 페이지 버튼으로 넘길 수 있습니다.
3. 사진에서도 줄 가이드와 범례 영역 선택 기능을 사용할 수 있습니다. 확대해서 기호를 확인하세요.
- 사진은 서버에 업로드되지 않고 현재 브라우저의 IndexedDB에 저장됩니다. 브라우저 저장 공간이 부족하면 복원되지 않을 수 있으므로 원본 사진은 따로 보관하세요.
- 사진을 추가하는 순서가 페이지 순서입니다. PDF를 새로 열면 현재 사진 목록은 대체됩니다.
- 촬영은 기기의 카메라·브라우저 지원에 따라 동작합니다. 실물 카메라 촬영은 별도 기기에서 직접 확인해야 합니다.

도안 기호 범례 보기
1. 범례가 그려진 PDF 페이지로 이동합니다.
2. 사이드바의 'PDF에서 범례 선택'을 누르고 기호와 설명이 있는 영역을 드래그합니다.
3. 사이드바에 고정된 범례를 확대 슬라이더와 가로/세로 스크롤로 살펴봅니다. 다른 페이지로 이동해도 유지됩니다.
4. 다른 범례를 고르려면 다시 선택하고, 없애려면 '해제'를 누릅니다.
- 선택 영역은 현재 브라우저에 저장되며 PDF를 다시 열면 해당 페이지에서 다시 렌더링됩니다.
- 기호의 뜻은 자동으로 판독하지 않습니다. 원본 PDF의 기호와 설명을 확대해 보여줍니다.

중요한 제한 사항
- PDF 렌더링과 한글 글꼴 매핑을 위해 인터넷에서 PDF.js 4.10.38 및 CMap 파일을 불러옵니다. 이 MVP는 완전 오프라인 보장 버전이 아닙니다.
- 텍스트 PDF의 M1 기호는 문자 위치에 따라 표시 오차가 있을 수 있고, 스캔 PDF/이미지 차트에서는 자동 감지가 불가능합니다.
- 현재 M1R/M1L 네 종류만 지원합니다. 도안의 약어 정의가 우선입니다.
- 단수와 실제 PDF 줄 위치는 독립적으로 관리됩니다(자동 단수 매핑은 미지원).
- 페이지마다 가이드 위치는 별도로 보관하지 않으며, 페이지 이동 시 가이드는 초기 위치로 이동합니다.
- 브라우저 데이터 삭제/시크릿 모드/저장 공간 부족 시 저장된 정보가 사라질 수 있습니다. 중요한 PDF의 원본은 별도 보관하세요.
