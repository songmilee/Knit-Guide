# Knit Guide v0.3

PDF 뜨개 도안의 단수와 슬라이딩 가이드를 함께 관리하는 정적 웹앱입니다. 사진 도안 보기와 기호 범례 고정 기능도 유지합니다.

## 사용 방법

1. GitHub Pages 또는 로컬 개발 서버에서 앱을 열고 PDF를 선택합니다. 새 PDF의 기본 시작 면은 **1단 = WS**입니다.
2. **1단 위치 설정**을 먼저 눌러 1단을 선택합니다. 가이드를 1단 위치로 옮긴 뒤 **1단 위치 확정**을 누릅니다.
3. 앱이 2단 설정으로 바뀌면 가이드를 2단 위치로 옮기고 **2단 위치 확정**을 누릅니다.
4. 다음/이전 단 버튼으로 저장된 위치에 이동합니다. 저장되지 않은 위치는 현재 PDF 페이지에서 간격을 알 수 있을 때만 추정합니다. 페이지 경계가 불확실하면 가이드는 움직이지 않습니다.
5. 일반 작업 중에는 가이드를 직접 움직여 현재 단의 위치를 보정합니다. 다른 단을 다시 보정할 때는 해당 단을 먼저 선택하세요. **현재 단 위치 저장**으로 다른 페이지의 기준 위치도 추가할 수 있습니다.
6. **자동 이동**을 끄면 단수만 변경됩니다. 확대·축소 후에도 상대 위치는 유지됩니다. 모바일에서는 화면 아래의 단수 버튼을 사용할 수 있습니다.

텍스트 PDF에서 `M1R`, `M1L`, `M1Rp`, `M1Lp`를 찾으면 해당 약어를 터치해 설명을 볼 수 있습니다. PDF 텍스트 추출은 도안의 구조에 따라 누락될 수 있으므로 **늘림 기법 툴팁**에서 수동으로 선택할 수 있습니다. **도안별 약어 정의**는 기본 설명보다 우선합니다. WS에서 `M1R`을 `M1Rp`로 자동 치환하지 않습니다.

## 로컬 저장과 향후 이전

- PDF 원본은 서버로 전송하지 않습니다. 사진은 마지막에 연 사진 묶음만 로컬에 보관합니다. 이 버전에서 열어 저장한 PDF는 SHA-256 해시별로 IndexedDB의 `files`에 보관하고, 마지막에 연 파일을 가리키는 기록도 남깁니다. 브라우저 저장 공간이 부족하면 파일 저장에 실패할 수 있으며 앱에서 안내합니다.
- 단수, 페이지·가이드 상대 좌표, 시작 면, 도안별 약어는 `patterns`에 PDF 해시별로 저장합니다. 각 기록에는 `schemaVersion`, `revision`, `updatedAt`이 있어 나중에 계정 저장소로 이전할 때 구분할 수 있습니다.
- **기록 내보내기·가져오기**는 진행 상태 JSON만 다룹니다. PDF 원본과 사진은 포함되지 않습니다. 가져올 때 기존 기록과 겹치면 덮어쓸지 선택합니다.
- 같은 PDF를 두 탭에서 수정해 기록이 충돌하면 자동으로 덮어쓰지 않습니다. **최신 기록 불러오기** 또는 **이 탭 기록으로 덮어쓰기**를 선택해야 합니다.
- 기존 버전의 마지막 PDF와 전역 진행 상태가 일치하는지 자동 확인할 수 없습니다. 이전 기록을 현재 PDF에 연결할지 사용자에게 묻고, 원본 전역 기록을 별도 백업 키에 보존합니다.
- 브라우저 저장 공간 삭제나 시크릿 모드 사용 시 로컬 기록이 사라질 수 있습니다. 기기 간 자동 동기화는 아직 제공하지 않습니다. 나중에 클라우드 저장을 추가할 때 각 기기의 로컬 기록을 로그인 후 이전해야 합니다.
- 1·2단 간격으로는 다른 페이지나 여러 차트 구역의 위치를 확신할 수 없습니다. 필요한 단의 위치는 직접 등록하세요.
- PDF.js와 한글 CMap 파일을 인터넷에서 불러옵니다. 완전한 오프라인 사용은 지원하지 않습니다.

## 개발과 검증

별도 빌드 과정 없이 `index.html`, `row-model.mjs`, `progress-store.mjs`를 같은 디렉터리에서 서빙하면 됩니다. 모듈 로딩과 IndexedDB 사용을 위해 HTTPS 또는 로컬 개발 서버에서 실행하세요.

```sh
python -m http.server 8000
node tests/row-model.test.mjs
```

위 명령의 자동 테스트는 위치 계산과 페이지 경계만 확인합니다. 브라우저에서는 단수 전환, 터치 드래그, PDF별 복원, 두 탭 충돌, 기록 내보내기·가져오기, 사진 기능을 별도로 확인했습니다. 실제 iPad Safari 기기 조작은 아직 검증하지 못했습니다.

## GitHub Pages

저장소의 Pages 소스는 **Deploy from a branch → `main` → `/ (root)`**입니다. PR을 `main`에 병합하면 정적 파일이 함께 배포됩니다. 주소는 <https://songmilee.github.io/Knit-Guide/>입니다. PR 브랜치는 공개 페이지에 반영되지 않습니다.
