# Knit Guide v0.3

PDF 뜨개 도안의 단수와 슬라이딩 가이드를 함께 관리하는 정적 웹앱입니다. 사진 도안 보기와 기호 범례 고정 기능도 유지합니다.

## 사용 방법

1. `index.html`을 정적 웹 서버나 GitHub Pages에서 열고 PDF를 선택합니다.
2. 도안의 시작 면을 RS 또는 WS로 지정합니다. 기본값은 **1단 = WS**입니다.
3. 파란 가이드를 1단 위치에 놓고 **1단 위치 등록**을 누릅니다. 앱이 2단으로 전환되면 가이드를 2단 위치로 옮기고 **2단 위치 등록**을 누릅니다.
4. 이후 다음/이전 단 버튼을 누르면 저장된 위치로 이동합니다. 같은 페이지에서 간격을 알 수 있는 경우에만 미등록 위치를 추정합니다. 페이지 경계를 판단할 수 없으면 가이드는 움직이지 않습니다.
5. 가이드를 직접 움직이면 현재 단의 페이지와 상대 위치가 보정되어 저장됩니다. 필요하면 **현재 단 위치 저장**으로 다른 페이지의 기준 위치를 추가합니다.
6. **자동 이동**을 끄면 단수만 변경됩니다. PDF 확대·축소 후에도 상대 위치는 유지됩니다.

텍스트 PDF에서 `M1R`, `M1L`, `M1Rp`, `M1Lp`를 찾으면 해당 약어를 터치해 설명을 볼 수 있습니다. 텍스트 추출이 되지 않는 PDF에서는 **늘림 기법 툴팁**을 열고 버튼으로 선택합니다. 도안에 다른 정의가 있다면 같은 패널의 **도안별 약어 정의**에 저장하세요. 저장한 정의가 기본 설명보다 우선합니다. WS에서 `M1R`을 자동으로 `M1Rp`로 바꾸지 않습니다.

## 저장과 제한

- PDF 원본은 서버로 전송하지 않습니다. 마지막에 연 PDF는 IndexedDB의 기존 `files` 저장 영역에 유지됩니다.
- PDF의 SHA-256 해시를 키로 하여 단수, 위치, 시작 면, 작업 면, 도안별 약어를 IndexedDB의 `patterns` 저장 영역에 분리해 보관합니다. 같은 PDF를 다시 열면 해당 기록을 복원합니다.
- 기존 v0.2 기록은 마지막에 열었던 PDF를 복원할 때 새 저장 영역으로 옮깁니다. 다른 PDF를 열어도 그 기록을 덮어쓰지 않습니다.
- 브라우저 저장 공간 삭제나 시크릿 모드 사용 시 기록이 사라질 수 있습니다. 이 버전은 기기 간 동기화를 제공하지 않습니다.
- 위치 추정은 1·2단이 같은 페이지에 등록된 경우에만 가능합니다. 다른 페이지의 위치나 차트 배열은 자동으로 인식하지 않습니다.
- PDF.js와 한글 CMap 파일을 인터넷에서 불러옵니다. 완전한 오프라인 사용은 지원하지 않습니다.

## 개발과 확인

별도 빌드 과정 없이 `index.html`과 `row-model.mjs`를 같은 디렉터리에서 서빙하면 됩니다. 모듈 로딩과 IndexedDB 사용을 위해 HTTPS 또는 로컬 개발 서버에서 실행하세요.

```sh
python -m http.server 8000
node tests/row-model.test.mjs
```

브라우저에서 `http://localhost:8000`을 열어 PDF를 불러올 수 있습니다. 테스트는 위치 계산의 페이지 경계 처리와 실제 PDF의 단수 등록, 복원, 약어 감지를 확인합니다.

## GitHub Pages

저장소의 Pages 소스는 **Deploy from a branch → `main` → `/ (root)`**입니다. PR을 `main`에 병합하면 `index.html`과 `row-model.mjs`가 함께 배포됩니다. 배포 주소는 <https://songmilee.github.io/Knit-Guide/>입니다. PR 브랜치는 현재 공개 페이지에 반영되지 않습니다.
